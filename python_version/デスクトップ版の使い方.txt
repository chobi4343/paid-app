====================================
有給管理アプリ - デスクトップ版（Tkinter）
ブラウザ不要、Pythonのみで動作
====================================

【実行方法】
------------------------------------------
1. ターミナルを開く

2. このフォルダに移動
   cd "/Users/chobi/AI制作/有給管理/python_version"

3. デスクトップアプリを起動
   python3 app_desktop.py

→ GUIウィンドウが開きます（ブラウザは不要）


【必要なもの】
------------------------------------------
- Python 3.8以上
- Tkinter（Pythonに標準で含まれています）
- python-dateutil（計算用）

インストール:
  pip3 install python-dateutil


【デスクトップ版の特徴】
------------------------------------------
✅ ブラウザ不要
✅ インターネット接続不要（完全オフライン動作）
✅ シンプルなGUI
✅ データはローカルJSONファイルに保存
✅ 軽量・高速


【できること】
------------------------------------------
✅ 従業員一覧の表示
✅ 検索機能
✅ 新規従業員の登録
✅ 従業員情報の編集
✅ 残日数の自動計算
✅ 部署マスター管理


【データ保存場所】
------------------------------------------
demo_data/
  ├── employees.json    # 従業員データ
  └── departments.json  # 部署データ


【操作方法】
------------------------------------------
- ダブルクリック: 従業員を編集
- 右クリック: （将来的にコンテキストメニュー）
- 検索バー: リアルタイム検索

【トラブルシューティング】
------------------------------------------
Q: ウィンドウが開かない
A: Tkinterが正しくインストールされているか確認
   python3 -c "import tkinter; print('OK')"

Q: データが表示されない
A: demo_data/ フォルダを削除して再起動
   rm -rf demo_data/
   python3 app_desktop.py

Q: エラーが出る
A: python-dateutilをインストール
   pip3 install python-dateutil


【3つのバージョン比較】
------------------------------------------
1. app.py (Streamlit + Firebase)
   → 本格運用、複数人で使用

2. app_demo.py (Streamlit + JSON)
   → ブラウザで試したい、見た目重視

3. app_desktop.py (Tkinter + JSON) ⭐
   → ブラウザ不要、シンプル、軽量


【推奨】
------------------------------------------
個人利用・オフライン環境 → app_desktop.py ⭐⭐⭐
社内ツール・見た目重視 → app_demo.py ⭐⭐
本格運用・複数拠点 → app.py ⭐
