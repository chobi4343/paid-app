# 🚀 クイックスタートガイド

## すぐに試したい方へ（5分で起動）

### 方法1: デモ版（Firebaseなし）⭐推奨

```bash
# 1. ディレクトリに移動
cd python_version

# 2. 必要なパッケージをインストール
pip3 install streamlit pandas python-dateutil

# 3. アプリを起動
streamlit run app_demo.py
```

✅ これだけでブラウザが開き、アプリが使えます！

---

### 方法2: Firebase連携版（本格運用）

#### ステップ1: セットアップ

```bash
cd python_version
bash setup.sh
```

#### ステップ2: Firebase設定

1. [Firebase Console](https://console.firebase.google.com/) にアクセス
2. プロジェクト設定 → サービスアカウント
3. 「新しい秘密鍵の生成」→ ダウンロード
4. ダウンロードしたJSONを `firebase_config.json` として保存

#### ステップ3: 起動

```bash
source venv/bin/activate
streamlit run app.py
```

## 🎯 主な機能

### ✅ できること
- 従業員情報の登録・編集・削除
- 有給休暇の付与記録（自動・手動）
- 有給休暇の取得記録
- 残日数の自動計算（時効2年考慮）
- 部署マスターの管理
- 検索・フィルタリング

### 📊 自動計算機能
- **正社員**: 勤続年数に応じて10〜20日を自動付与
- **パート**: 週所定労働日数に応じた比例付与
- **時効**: 付与から2年で自動失効
- **消化**: FIFO方式（古いものから消化）

## 💡 使い方のヒント

### 従業員を登録する
1. トップページで「新規登録」をクリック
2. 必須項目（コード、名前、入社日）を入力
3. 「保存」をクリック
4. → 自動的に法定付与が計算されます

### 有給を付与する
1. 従業員を選択して「編集」
2. 「付与履歴」セクションで日付と日数を入力
3. 「付与追加」をクリック
4. → 残日数に反映されます

### 有給を取得する
1. 従業員を選択して「編集」
2. 「取得履歴」セクションで日付と日数を入力
3. 「取得追加」をクリック
4. → 残日数から差し引かれます

### 部署を管理する
1. 「設定」をクリック
2. 新しい部署名を入力して「追加」
3. → 従業員登録時に選択できるようになります

## 🔧 トラブルシューティング

### エラー: `ModuleNotFoundError: No module named 'streamlit'`
```bash
pip3 install streamlit
```

### エラー: `firebase_admin.exceptions.InvalidArgumentError`
- `firebase_config.json` のパスを確認
- ファイルの中身が正しいJSONか確認

### アプリが起動しない
```bash
# Python バージョン確認（3.8以上必要）
python3 --version

# Streamlit バージョン確認
streamlit --version

# 再インストール
pip3 install --upgrade streamlit
```

### データが表示されない（デモ版）
```bash
# デモデータをリセット
rm -rf demo_data/
streamlit run app_demo.py
```

- **ネットワーク**: http://[あなたのIP]:8501
